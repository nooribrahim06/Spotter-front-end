Inside every state folder
-------------------------
PNG/
    Transparent PNG exports:
    - 128 px long edge
    - 256 px
    - 384 px
    - 512 px
    - 768 px
    - 1024 px
    - 1536 px
    - plus the extracted MASTER crop

WEBP/
    Lossless transparent WebP versions of the same long-edge sizes.

SQUARE_PNG/
    Transparent square canvases:
    - 256x256
    - 512x512
    - 768x768
    - 1024x1024

Recommended usage
-----------------
128–256:
    Tiny UI states, tooltips, notifications.

384–512:
    Cards, chat coach UI, empty states, dashboard moments.

768–1024:
    Onboarding, auth screens, landing-page sections.

1536:
    Large layout / high-density use.

Important resolution note
-------------------------
These seven states came from the generated 1536x1024 sprite sheet, so each
individual state's true source resolution is roughly one quadrant of that sheet.

The 768 / 1024 / 1536 exports are high-quality resizes of the exact state artwork;
they are NOT newly generated higher-detail renders.

If you later want true native high-resolution masters for each state, each state
should be regenerated individually while locking the same Spotter character identity.
